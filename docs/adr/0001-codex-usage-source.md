# Keep subscription collection isolated and read-only

The approved homelab design replaces ESP32-owned private Codex fetching with a Rust server that reads the local Codex App Server over stdio and sends normalized provider snapshots through authenticated LAN-only MQTT. The ESP32 owns presentation and local countdowns, never provider credentials. Codex refresh remains owned by its isolated CLI credential store; Claude's independent Raycast-style OAuth usage collector is an explicitly opted-in, unsupported experiment with an isolated credential directory and a single refresh writer. This keeps credentials off the display and polling independent of the MacBook, at the cost of operating the homelab server and broker. Private API or account rejection is surfaced without bypasses. The monitor never invokes inference, purchases, or manual reset redemption; manual resets remain on the provider website.
